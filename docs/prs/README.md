# PR descriptions

Archived copies of pull-request descriptions kept alongside the code
for traceability. Each file in this directory corresponds to one branch
pushed to the fork (`github.com:95499029/hermes-agent`).

When a PR gets reviewed and the description needs to be referenced
later (or the upstream PR URL is lost), the matching file here is the
authoritative copy.

Files:

- `agent-intelligence.md` — PR for the `feat/agent-intelligence-skill`
  branch. Adds the `agent-intelligence` skill (a context-economics +
  tool-trust-tier meta-skill), disables the MoA picker entry, and
  renames the `opencode-free` provider to `_opencode-free`.
